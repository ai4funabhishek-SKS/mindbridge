How to Get API Keys

Groq (Free)
  1. Go to console.groq.com/keys
  2. Sign in with GitHub/Google
  3. Click "Create API Key"
  4. Copy key (starts with gsk_)
OpenCode Zen
  1. No API key needed!
  2. Just select "opencode" as provider
  3. Uses freemodel by default
Ollama (Local)
  1. Install Docker Desktop
  2. Run: wsl ollama pull llama3.2
  3. No API key needed
OpenAI Compatible
  1. Get key from provider dashboard
  2. Set base URL (e.g., OpenAI, Azure, local)
  3. Enter key and select model
