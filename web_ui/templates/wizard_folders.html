Watch Folders

Configure folders to monitor for new files. mindbridge will automatically classify, enrich, and index new files.

Folder Setup Tips

  • Desktop/Downloads: Great for capturing daily downloads and screenshots
  • Documents/Inbox: Perfect for documents you want to process later
  • Raw_copies/incoming: Drop files here for immediate processing
  • Recursive vs Flat: Recursive scans subfolders; flat only checks top level
  • Patterns: Use glob patterns like *.pdf, *.md, *.txt
