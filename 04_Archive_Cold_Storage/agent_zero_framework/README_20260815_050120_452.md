# Personal Knowledge Management System

This is a structured knowledge management system designed for RAG (Retrieval Augmented Generation) and LLM training purposes.

## Folder Structure

- `/sources` - Original content from WhatsApp and other sources
  - `/youtube` - YouTube video transcripts and notes
  - `/pdfs` - PDF documents and their summaries
  - `/images` - Images and their descriptions
  - `/tables` - Data tables and their analyses
  - `/flowcharts` - Flowcharts and process diagrams
  - `/n8n` - n8n templates and workflows
  - `/json` - JSON data files

- `/moc` - Maps of Content for knowledge organization
- `/templates` - Metadata and note templates
- `/processed` - Processed and enriched content ready for RAG/LLM

## Getting Started

1. Place your original content in the appropriate subfolder under `/sources`
2. Use the templates in `/templates` for consistent metadata tagging
3. Create MOCs in the `/moc` folder to organize related content
4. Processed files will be stored in `/processed` for RAG/LLM use

## Metadata Structure

Each document should include:
- Title
- Source
- Date Added
- Content Type
- Tags
- Summary
- Related MOCs
