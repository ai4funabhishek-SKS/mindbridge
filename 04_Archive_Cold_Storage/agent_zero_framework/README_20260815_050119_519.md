## 🔧 Manual Configuration Steps

### 1. Copy Settings to Cursor
```bash
# Windows
copy settings.json "%APPDATA%\\Cursor\\User\\settings.json"
copy keybindings.json "%APPDATA%\\Cursor\\User\\keybindings.json"

# macOS
cp settings.json "~/Library/Application Support/Cursor/User/settings.json"
cp keybindings.json "~/Library/Application Support/Cursor/User/keybindings.json"

# Linux
cp settings.json "~/.config/Cursor/User/settings.json"
cp keybindings.json "~/.config/Cursor/User/keybindings.json"
```

### 2. Configure MCP Servers
```bash
# Copy MCP configuration
cp mcp_config.json "%APPDATA%\\Cursor\\User\\mcp_config.json"
```

### 3. Set Up Git
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

## 🔍 Troubleshooting

### Common Issues
1. **Extensions not installing**: Restart Cursor and try again
2. **Copilot not working**: Check authentication and internet connection
3. **Settings not applying**: Verify file paths and restart Cursor
4. **MCP servers failing**: Ensure Node.js is installed and paths are correct
