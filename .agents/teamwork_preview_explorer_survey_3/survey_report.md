- **Execution Modes**:
  - `--mode linear` (Default): SQLite FTS5 BM25 search over extracted text chunks
  - `--mode graph`: Knowledge Graph node and relationship inspection

### 1.2 Linear Search Engine (FTS5 & BM25)
- **Function**: `search_linear(query: str, limit: int = 8)` (Lines 16-63)
- **Query Processing**:
  - Sanitizes and formats query terms into prefix search tokens:
    ```python
    formatted_query = " ".join([f'"{q}"*' for q in query.split() if q.strip()])
    ```
- **SQL Query**:
  ```sql
  SELECT 
      asset_title,
      file_name,
      topic,
      problem_solved,
      snippet(chunks_fts, 0, '>>> ', ' <<<', '...', 25) as snippet_text,
      bm25(chunks_fts) as rank
  FROM chunks_fts
  WHERE chunks_fts MATCH ?
  ORDER BY rank
  LIMIT ?;
  ```
- **FTS5 Features Utilized**:
  - `bm25(chunks_fts)`: Calculates relevance ranking scores based on token frequency and inverse document frequency.
  - `snippet(chunks_fts, 0, '>>> ', ' <<<', '...', 25)`: Highlights matched terms within column index 0 (`chunk_text`) with prefix `>>> `, suffix ` <<<`, and contextual length of 25 tokens.
- **Output Interface**: Formatted console output displaying Result Rank, Asset Title, Source Filename, Topic, Absolute Rank Score, Problem Solved, and contextual snippet.

### 1.3 Knowledge Graph Traversal Engine
- **Function**: `search_graph(entity: str)` (Lines 65-121)
- **Node Matching**:
  - Queries `kg_nodes` table using case-insensitive substring matching on both node ID and label:
    ```sql
    SELECT id, label, node_type, details FROM kg_nodes WHERE id LIKE ? OR label LIKE ?;
    ```
- **Relationship Resolution**:
  - **Inbound References** (Assets utilizing or citing this entity):
    ```sql
    SELECT e.relationship, n.label, n.node_type
    FROM kg_edges e
    JOIN kg_nodes n ON e.source_id = n.id
    WHERE e.target_id = ?
    LIMIT 10;
    ```
  - **Outbound Connections** (Entities referenced by this asset):
    ```sql
    SELECT e.relationship, n.label, n.node_type
    FROM kg_edges e
    JOIN kg_nodes n ON e.target_id = n.id
    WHERE e.source_id = ?
    LIMIT 10;
    ```
- **CLI Interface**:
  - Example: `python search_engine.py "n8n" --mode linear --limit 10`
  - Example: `python search_engine.py "Pinecone" --mode graph`

#### Detailed Table Specifications:

1. **`documents` Table**:
   - `id`: `INTEGER PRIMARY KEY AUTOINCREMENT`
   - `file_name`: `TEXT` (Source file name)
   - `relative_path`: `TEXT UNIQUE` (Relative path from source root)
   - `asset_title`: `TEXT` (Extracted or sanitized title)
   - `format`: `TEXT` (`.json`, `.pdf`, `.md`, `.docx`, `.xlsx`, `.txt`)
   - `topic`: `TEXT` (Primary domain categorization)
   - `problem_solved`: `TEXT` (Functional utility description)
   - `workability`: `TEXT` (`Production-Ready Workflow`, `Deployable Prompt Template`, `Algorithmic Rules`, `Reference Documentation`, etc.)
   - `rating`: `TEXT` (`Must Keep - High Reusability`, `Sensitive (Private Vault)`, `Half-Baked Idea (R&D Mine)`, `Reference Knowledge`)
   - `tags`: `TEXT` (Comma-delimited technologies, e.g., `n8n, Workflow Automation, Webhook`)
   - `size_kb`: `REAL`
   - `created_at`: `TIMESTAMP DEFAULT CURRENT_TIMESTAMP`

2. **`chunks` Table**:
   - `id`: `INTEGER PRIMARY KEY AUTOINCREMENT`
   - `doc_id`: `INTEGER REFERENCES documents(id) ON DELETE CASCADE`
   - `chunk_index`: `INTEGER` (0-indexed position within document)
   - `chunk_text`: `TEXT` (Text window of 1,200 characters with 200 character overlap)
   - `char_count`: `INTEGER`

3. **`chunks_fts` Virtual Table (FTS5)**:
   - Engine: `fts5(chunk_text, asset_title UNINDEXED, topic UNINDEXED, problem_solved UNINDEXED, file_name UNINDEXED, tokenize = 'porter unicode61')`
   - Tokenizer: Porter Stemmer + unicode61 tokenizer for robust morphological matching (e.g., "automating" matches "automation").

4. **`kg_nodes` Table**:
   - `id`: `TEXT PRIMARY KEY` (e.g., `n8n`, `pinecone`, `doc_14`, `deepseek`)
   - `label`: `TEXT` (Display title / name)
   - `node_type`: `TEXT` (`Tool`, `AI Provider`, `AI Model`, `Vector DB`, `Platform`, `Language`, `Domain`, `Discipline`, `Communication`, `Document`)
   - `details`: `TEXT` (Metadata and format descriptions)
   - `count`: `INTEGER DEFAULT 1`

5. **`kg_edges` Table**:
   - `id`: `INTEGER PRIMARY KEY AUTOINCREMENT`
   - `source_id`: `TEXT REFERENCES kg_nodes(id)`
   - `target_id`: `TEXT REFERENCES kg_nodes(id)`
   - `relationship`: `TEXT` (`USES_OR_REFERENCES`)
   - `weight`: `REAL DEFAULT 1.0`
